# Анализ транзакций в dbt

ClickHouse → staging → шесть витрин: дневные метрики, фрод по категориям и штатам, риск клиентов, временные паттерны и аналитика мерчантов

Склонируйте репозиторий и перейдите в его каталог. Нужны Docker Compose v2, uv и make. Положите `train.csv` из HW1 в `data/` (создайте папку)

```bash
make setup up load deps build lint docs
make serve
```

[Документация](http://localhost:8082). Значок справа внизу открывает DAG. [Скриншот](results/dbt-dag.png) · [Результат тестов](results/dbt-test.log)

Витрины — в базе `analytics`, модели и их описания — в `dbt/models/`. Доли считаются в процентах. Пороги рассчитаны по `train.csv`: суммы — P75/P95 (83/195,97), HIGH клиента — P75 долей фрода (≈1,1844%), подозрительный мерчант — P95 (≈1,7473%). MEDIUM клиента — ненулевая доля ниже HIGH, LOW — 0%. Точные границы — в `dbt/dbt_project.yml`

Ключ клиента приближённый: имя, фамилия и координаты. `make load` очищает исходную таблицу HW4 и загружает CSV заново; после ошибки загрузки повторите эту команду

34 проверки данных и 8 unit tests. Повторная проверка и установка хука pre-commit:

```bash
make test
.venv/bin/pre-commit install
```

Завершить `make serve` — Ctrl+C. Остановить ClickHouse — `make stop`
